# video

Video producer. Use to script, storyboard, generate, edit and render videos — HTML compositions (HyperFrames), React video (Remotion), GSAP motion, captions, TTS, site-to-video, in any repo.

An agent for [hq](https://github.com/Ying-Kai-Liao/hq): a specialist that runs in Claude Code with its own memory,
skills and tools, on your own Mac.

```
hq install Ying-Kai-Liao/hq-video
```

`hq install` shows what it may do on your Mac (permissions, tools, services) before keeping it. Its memory and data
stay yours; updating it (`hq update video`) never touches them.
